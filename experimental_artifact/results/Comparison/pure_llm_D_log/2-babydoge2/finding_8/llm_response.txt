        token = IBabyDogeCoin20(TARGET);
        owner = token.owner();

        // For events, vm.getRecordedLogs() works.
        // We'll record before, then call, then compare.
        Vm.Log[] memory logsBefore = vm.getRecordedLogs();

        Vm.Log[] memory logsAfter = vm.getRecordedLogs();

        // Note: The contract does emit Transfer events, but those are from the call? No, setSellTax doesn't transfer.
        // So logsAfter should have same length as logsBefore (or we can just check isEmpty).
        // However, vm.getRecordedLogs() might include other actions; better to check that no event with topic for "SellTaxSet" exists.

        // But the test already emitted some Transfer events during setup. We'll just do a dedicated check.

        emit Something(0); // This event does not exist, so we expect it is NOT emitted.
        // Actually, vm.expectEmit sets up an expectation that the next call will emit the given event.
        // If the call emits exactly that event, it's fine; otherwise it fails.
        // To check that no event is emitted, we can use a trick: expectEmit with a dummy event that is unlikely.
        // But we cannot use a non-existent event. We'll just use a simple emit Transfer but with wrong data? No.
